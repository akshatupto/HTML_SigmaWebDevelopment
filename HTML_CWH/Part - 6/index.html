Seo and Core web Vitals

SEO stands for Search Engine Optimization, which is the practice of improving a website to increase its visibility and rank higher in search engine results. Core Web Vitals are a specific subset of metrics created by Google that measure real-world user experience regarding page loading speed, interactivity, and visual stabilit.
